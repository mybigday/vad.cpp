# Audio: assets/test_16k.wav (67.8 s). vad-bench -s 16 -r 3; Metal only at t=1 (threads don't apply).
# Native macOS build, ggml defaults (GGML_NATIVE, Accelerate/BLAS, Metal); vad-cpu selects the ARMv8.2 variant.
#
# Summary:
# - vad-cpu beats ggml-cpu on every row (1.2x to 4.8x).
# - Metal loses on all streaming models: ~800-1200 us per single-hop push (command-buffer round trip).
# - Metal wins only on firered-vad (non-streaming) at t=1 for offline/many streams; at t=4 vad-cpu
#   matches or beats it (offline q8_0: cpu 4.97 vs Metal 8.18).
#
# iOS builds target ARMv8.0 (apple-a7) by default. Before the ARMv8.2 variant was built for Apple targets,
# F16/Q8_0 ran the plain path there. Same machine, -mcpu=apple-a7, vad-cpu t=1, old (generic) -> new (armv8.2):
#   silero-v6.2-f16          stream 25.09 -> 20.44   streams S=16 22.03 -> 18.22

#   firered-stream-vad-f16   stream 41.36 -> 35.94   streams S=16 30.99 -> 27.76
#   firered-stream-vad-q8_0  stream 57.50 -> 35.14   streams S=16 32.27 -> 21.20
