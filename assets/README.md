# Test assets

- `jfk.wav`: 11 s, 16 kHz mono speech sample, copied from
  [whisper.cpp](https://github.com/ggml-org/whisper.cpp/tree/master/samples) (MIT).

Generated files (`*.f32`, `*.npy`, `test_16k.wav`) are not tracked. Run
`scripts/prepare-test-data.sh` to create the models and references used by the tests.
